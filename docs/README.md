# Documentation Index

This directory contains reference material for the platform. These files describe how the system is designed, secured, operated, and validated.

## Structure

| Directory | Purpose |
|---|---|
| `architecture/` | Infrastructure baseline, topology, scaling, observability, prerequisites, and architecture decisions |
| `architecture/decisions/` | Architecture decision records and alternatives |
| `architecture/modularity/` | Component interfaces, dependency mapping, configuration standards, and resource standards |
| `operations/` | Build instructions, runbooks, disaster recovery, test scripts, baselines, onboarding, and patch management |
| `security/` | Security architecture, hardening, incident response, secrets, and network security |
| `regulatory/` | Compliance matrix, ISO 27001 mapping, risk register, suppliers, SoA, and glossary |
| `Platform Primer.md` | Plain English orientation for the whole platform |

## Rule

Use `docs/` for durable reference documents. Use `plans/` for phase work, roadmap, and strategy. Use `records/` for build logs and evidence.
