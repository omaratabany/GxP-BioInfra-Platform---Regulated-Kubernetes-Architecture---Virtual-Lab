# Records Index

This directory contains build records and implementation evidence.

## Structure

| File | Purpose |
|---|---|
| `OPS-03 Implementation Log.md` | Timestamped build log, issue tracker, phase completion checklist, component registry, and checksum registry |

## Rule

Use `records/` for evidence of what actually happened. Do not store secrets, kubeconfigs, talosconfigs, or etcd snapshots in Git.
