# Plans Index

This directory contains planning material. These files describe what will be built, why it matters, and how the phases are sequenced.

## Structure

| Directory | Purpose |
|---|---|
| `phases/` | Phase-by-phase implementation plans and current status |
| `roadmap/` | Phase map, schedule, and future improvements |
| `strategy/` | Project rationale, significance, CKA alignment, and public portfolio material |

## Rule

Use `plans/` for intended work and project direction. Move completed build evidence into `records/`, and stable operating guidance into `docs/`.
